# API 配置指南

## 🔧 如何修改 API 地址（IP）

### 步骤

只需要修改 **一个文件** 即可全局生效：

1. 打开项目根目录的 `.env` 文件
2. 修改 `DIFY_API_HOST` 的值
3. 重启开发服务器

### 📁 文件位置

```
项目根目录/.env
```

### 📝 配置格式

```bash
# API 配置
# 修改这里的 IP 地址即可全局生效
DIFY_API_HOST=127.0.0.1:8081
```

### 🌰 使用示例

#### 本地开发
```bash
DIFY_API_HOST=127.0.0.1:8081
```

#### 局域网测试
```bash
DIFY_API_HOST=192.168.1.100:8080
```

#### 远程服务器
```bash
DIFY_API_HOST=10.1.100.110:8081
```

### ⚠️ 注意事项

1. **修改后需要重启开发服务器**
   ```bash
   # 停止当前服务器（Ctrl+C）
   # 然后重新启动
   pnpm dev
   ```

2. **格式要求**
   - 必须是 `IP:端口` 格式
   - 不要加 `http://` 或 `https://` 前缀
   - 等号两边不要有空格

3. **生效范围**
   修改 `.env` 后，以下所有地方都会自动更新：
   - ✅ 登录请求地址
   - ✅ 知识库 API 请求
   - ✅ Vite 开发服务器代理
   - ✅ 所有 Dify API 调用

### 🔍 验证配置

启动后，可以通过以下方式验证：

1. **查看控制台日志**
   ```
   🔐 发起登录请求：http://你的IP:端口/console/api/login
   ```

2. **查看 Vite 代理日志**
   ```
   Sending Request to the Target: POST /console/api/login
   ```

3. **打开浏览器开发者工具 → Network 面板**
   - 查看请求的 URL 是否正确

### ❓ 常见问题

**Q: 修改后不生效？**
A: 确保重启了开发服务器（Ctrl+C 停止，然后重新 `pnpm dev`）

**Q: 可以同时有多个环境配置吗？**
A: 可以创建不同的 `.env` 文件：
- `.env.development` - 开发环境
- `.env.production` - 生产环境
- `.env.test` - 测试环境

Vite 会根据 `NODE_ENV` 自动加载对应的文件。

**Q: 如果环境变量和 .env 都设置了，哪个生效？**
A: 系统环境变量的优先级高于 `.env` 文件。
